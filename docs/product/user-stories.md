# User Stories

## Customer
- As a user, I want to submit a service ticket so I can request IT help.
- As a user, I want to track my ticket so I know what’s happening.
- As a user, I want to message the technician so I can provide details.
- As a user, I want an emergency contact option so I can escalate critical issues.

## Technician
- As a technician, I want to see assigned tickets so I can work efficiently.
- As a technician, I want messaging to stay within the ticket so context is preserved.

## Admin
- As an admin, I want to create groups and domains.
- As an admin, I want to assign and reassign tickets.
- As an admin, I want audit logging for compliance.
